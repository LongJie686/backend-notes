# 办公电脑

日常开发用的 Windows 电脑。常驻服务大多已迁到[辅助电脑](/projects/infra/aux-pc)，
这里只保留两类：开发要用的，和**必须依赖本机数据**的。

## 保留在这台的任务

| 类型 | 做什么 | 为什么不迁 |
|------|-------|-----------|
| 趋势采集 | 用带登录态的浏览器抓取平台趋势，供线上创意生图使用 | 依赖本机浏览器登录态 |
| 用量采集 | 汇总本机开发工具的模型用量，上报到 CrossSail 看板 | 数据只在本机 |
| 管理后台隧道 | 开机建立到辅助电脑管理后台的隧道 | 管理入口只在办公电脑开放 |
| 模型网关客户端隧道 | 把本地端口映射到辅助电脑的模型网关 | 客户端统一连本地端口 |

## 常驻任务的写法

- **Windows 计划任务 + `wscript //B` 调 `.vbs`**：后台静默运行，不弹黑窗口。
  启动脚本保持纯 ASCII + CRLF，含中文的 `.bat` 会被 cmd 按 GBK 解析错乱。
- **采集任务分三段**：预检（探测登录态是否有效）→ 正式采集 → 保活（定期刷新会话），
  登录态失效时预检就能提前发现，而不是等正式采集失败。
- **隧道由守护脚本维持**：`ssh -N -L` 配 `ExitOnForwardFailure`、`ServerAliveInterval`，
  断了由守护脚本重连，而不是靠 ssh 自己。

## 开发环境的几个坑

- **代理分流**：国内服务（钉X、腾讯系、国内模型 API）必须走直连，
  否则海外节点 IP 访问国内接口容易被风控。Electron / CEF 客户端不读系统代理白名单，
  要在代理软件的规则里加 DIRECT 才能真正生效。
- **PowerShell 5.1**：调外部程序时参数里的双引号会被拆掉；
  `2>$null` 会干扰原生程序的输出捕获。
